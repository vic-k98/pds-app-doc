# PDS-APP — 矿区车载安全设备程序升级 App

| 路径 | 说明 |
|---|---|
| `docs/PRD.md` | 产品需求文档主稿（Markdown + Mermaid 流程图，可直接导入飞书文档） |
| `docs/PRD.docx` | Word 版本（流程图已渲染为图片），用于飞书附件或无 Mermaid 渲染的场合 |
| `docs/images/fig-*.png` | 7 张流程图 / 状态机 / 架构图 PNG |
| `docs/images/ui-*.png` | 11 张 App 界面原型截图（英文界面） |
| `prototype/pds-app-prototype.html` | 高保真可点击原型（界面文案英文，见 PRD 6.7），浏览器直接打开；`?screen=upgrading` 可定位到指定页面 |

## 上传飞书

- 方式一：飞书文档 → 导入 → 选择 `docs/PRD.md`（Mermaid 代码块会自动渲染；图片需在导入后从 `docs/images` 手动插入，或改用方式二）
- 方式二：飞书文档 → 导入 → 选择 `docs/PRD.docx`（流程图与界面截图已内嵌）
- 原型 HTML 可作为附件上传到飞书云空间，或放到内网静态站点后在 PRD 中贴链接
